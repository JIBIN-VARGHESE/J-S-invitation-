Place your background music here as `wedding.mp3` (or change `music.src` in `config.js`).

- The music button only appears once this file exists.
- Music never autoplays; guests tap the button to start it.
- Keep the file small: a 128 kbps MP3 of 3–4 minutes is about 3–4 MB. It loops.
- Use music you have the right to share publicly.
